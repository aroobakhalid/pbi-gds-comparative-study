-----------------------------------------------------------
AMAZON DASHBOARD - SCATTER CHART LABEL ABBREVIATION
-----------------------------------------------------------

Field Name: Category_abbv
Purpose: Abbreviate full product category names to resolve 
         scatter chart label overlap in GDS
Used in: Category Performance Matrix (Scatter Chart)
Reason: GDS scatter chart rendered full-length category names 
        with considerable overlap; this CASE-based field was 
        created as a workaround to improve readability

CASE 
  WHEN product_category = "Beauty" THEN "BTY"
  WHEN product_category = "Books" THEN "BKS"
  WHEN product_category = "Fashion" THEN "FSH"
  WHEN product_category = "Home & Kitchen" THEN "H&K"
  WHEN product_category = "Electronics" THEN "ELC"
  WHEN product_category = "Sports" THEN "SPT"
  ELSE "Misc"
END

------------------------------------------------------------
WALMART DASHBOARD - SCATTER CHART LABEL ABBREVIATION
------------------------------------------------------------

Field Name: category_abv
Purpose: Same as above - abbreviate product line names for 
         scatter chart readability in GDS
Used in: Category Performance Matrix (Scatter Chart)

CASE 
  WHEN Product_line = "Food and beverages" THEN "F&B"
  WHEN Product_line = "Fashion accessories" THEN "FA"
  WHEN Product_line = "Electronic accessories" THEN "EA"
  WHEN Product_line = "Home and lifestyle" THEN "H&L"
  WHEN Product_line = "Sports and travel" THEN "S&T"
  WHEN Product_line = "Health and beauty" THEN "H&B"
  ELSE "Other"
END

Note: This label handling behaviour was observed in the default 
scatter chart configuration of GDS at the time of evaluation.
