DAX MEASURES USED IN THIS STUDY

Paper: Comparative Analysis of Data Visualization Tools and 
       Techniques: A Case Study of Power BI and Google Data Studio
Platform: Microsoft Power BI Desktop 2.154.1260.0 (64-bit)


------------------------------------------------------------
AMAZON DASHBOARD - GAUGE TARGET MEASURES
------------------------------------------------------------

1. AmazonRevenue
   Purpose: Calculate total revenue for the Amazon dataset
   Used in: Gauge visual (Value field)
   
   AmazonRevenue = SUM(amazon_sales_dataset[total_revenue])

2. AmazonTarget
   Purpose: Calculate target benchmark at 2.5x actual revenue
   Used in: Gauge visual (Target value field)
   Rationale: Uniform scaling factor of 2.5 applied to observed 
              total revenue, representing a 150% aspirational 
              growth benchmark (Section 3.1.3 of paper)
   
   AmazonTarget = [AmazonRevenue] * 2.5

   Result: $32.87M x 2.5 = approximately $82.2M

------------------------------------------------------------
WALMART DASHBOARD - GAUGE TARGET MEASURES
------------------------------------------------------------

3. WalmartRevenue
   Purpose: Calculate total revenue for the Walmart dataset
   Used in: Gauge visual (Value field)
   
   WalmartRevenue = SUM('WalmartSalesData csv (1)'[Total])

4. WalmartTarget
   Purpose: Calculate target benchmark at 2.5x actual revenue
   Used in: Gauge visual (Target value field)
   Rationale: Same uniform scaling factor of 2.5 as Amazon
   
   WalmartTarget = [WalmartRevenue] * 2.5

   Result: $322.97K x 2.5 = approximately $807.42K

------------------------------------------------------------
NOTES
------------------------------------------------------------
Both target measures recalculate dynamically when slicer 
  selections modify the filter context
The same 2.5x multiplier was applied consistently across 
  both datasets to maintain proportional equivalence
GDS gauge does not support calculated field-based targets; 
  the equivalent values ($82.2M and $807.42K) were entered 
  as static constants in the GDS chart configuration
